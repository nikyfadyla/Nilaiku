# 📚 Nilaiku

## **Nilaiku** adalah aplikasi prediksi nilai ujian berdasarkan keseharian siswa

## 🚀 Fitur Utama

- ⚡ Fast development dengan Vite
- 🎨 Styling modern dengan Tailwind CSS
- ✨ Animasi dengan Framer Motion & AOS
- 📊 Visualisasi data dengan Recharts
- 🧠 Form handling & validasi dengan React Hook Form
- 💡 Ikon modern dari Lucide dan Remixicon
- 🚪 Navigasi dengan React Router DOM

## 📦 Daftar Paket yang Digunakan

1. framer-motion
2. lucide-react
3. tailwindcss
4. postcss
5. remixicon
6. aos (Animate On Scroll)
7. react-router-dom
8. react-hook-form
9. recharts

## 🛠️ Instalasi & Menjalankan Proyek

### Prasyarat
- Node.js (versi 16 atau lebih baru)
- npm atau yarn

### Langkah-langkah

1. **Clone Repository**
```bash
git clone https://github.com/username/nilaiku.git
cd nilaiku
```

2. **Instal Dependencies**
```bash
npm install
```

3. **Instal Paket Tambahan**
```bash
npm install tailwindcss postcss autoprefixer @tailwindcss/vite
npm install framer-motion
npm install aos
npm install react-router-dom
npm install react-hook-form
npm install recharts
npm install lucide-react
npm install remixicon
```

4. **Menjalankan Aplikasi**
```bash
npm run dev
```

5. **Build untuk Produksi**
```bash
npm run build
